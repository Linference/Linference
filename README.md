## 01 — 关于

我是 **LIN KIT**，澳门濠江中学的一名学生开发者。

白天上课，晚上写代码。喜欢的事很具体：让一段文字变成可以追问的对话，让一张照片变成能逐笔回放的画，让一栋普通骑楼在三维里被记住。

名字里的 *inference* 既是推理，也是「让想法得出结论」的过程 —— 所以我更愿意把好奇心的终点，放在一个**能打开、能操作、能交到别人手上**的东西上。
