## 🧭 关于我

我是 **LIN KIT**，澳门濠江中学的一名学生开发者。

写代码对我来说更像是「把好奇心落地」的方式：看到一个有意思的效果，就想知道它是怎么算出来的；想清楚之后，又忍不住把它做成一个能点开、能跑、能给别人用的东西。

所以我的仓库大多长这样——**一个具体的场景 + 一套自己搭的流水线 + 一点点强迫症级别的打磨**。

- 🔭 目前在折腾：笔触渲染、多智能体工作流、把校园里的事做成系统
- 🌱 正在补课：深度学习、数据结构与算法、CS 基础
- 🧪 喜欢的方向：非真实感渲染（NPR）、扩散模型、Agent 工程化
- ⚡ 一个小事实：名字里的 *inference*，既是推理，也是「让想法得出结论」的过程
